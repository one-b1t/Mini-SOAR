### P0 yang ditemukan belakangan
`auth_guard` **mematikan bot saat start.** Handler python-telegram-bot memakai
`__slots__`, jadi `_handler._minisoar_guarded = True` melempar
`AttributeError`; `main()` hanya menangkap `KeyboardInterrupt` → proses mati
di handler pertama. Bot tidak pernah start sejak middleware dipasang.

Perbaikan: flag dipindah ke fungsi wrapper `auth_guard` (plain function punya
`__dict__`), dibaca dari `_handler.callback`. Commit `108d585`.

**Pelajaran:** 3 test `auth_guard` tetap hijau karena hanya menguji
dekorasinya, tidak pernah memanggil `main()`. Smoke test Layer-2 juga hijau
karena `getMyCommands()` membaca daftar command **di sisi server Telegram**
lewat `post_init`, bukan `app.handlers`. Dua-duanya buta.

Test regresi: `tests/test_bot.py::test_main_installs_auth_guard_on_every_handler`
memanggil `main()` sungguhan dengan `ApplicationBuilder` di-stub. Diverifikasi
bergigi: kode lama → `AttributeError` identik dengan crash produksi.

### Temuan yang masih terbuka

**a. `/blocked` — NO_REPLY reproducible.** Bot tidak mengirim balasan sama
sekali ketika Redis mati. Handler memanggil
`await asyncio.to_thread(get_active_blocklist)` → `bot.py:1330`. Bot mencatat
`Failed to read perimeter blocklist from Redis: Error 111 connection refused`
lalu **tidak pernah reply**. Tidak ada traceback. Root cause belum dicari.

**b. Redis tidak berjalan.** `127.0.0.1:6379 Connection refused` sepanjang
sesi. Handler yang bergantung pada Redis akan gagal. Perlu start Redis
sebelum test berikutnya.

**c. 2× `Unhandled exception` saat beban.** Keduanya `reply_text` timeout ke
API Telegram:
- `bot.py:330` `blockonpalo` → `httpx.ConnectTimeout`
- `bot.py:843` `restorehost` → `telegram.error.TimedOut`

Keduanya **hilang** saat bot idle (re-test OK). Jadi bukan bug deterministik,
tapi tetap risiko operasional: tidak ada `try/except` di body handler, jadi
satu timeout ke Telegram membiarkan user tanpa balasan sama sekali.

**d. `/activate_akamai` TIDAK di-guard `MINISOAR_MOCK`.** Handler memanggil
`session.post` langsung ke API Akamai **nyata** dengan kredensial asli dari
`.env`:
```
AKAMAI_BASEURL = https://akab-lvxx7xaelgbg2v-1818313600.luna.akamaiapis.net
list 217280_IPBLOCKLIST, network PRODUCTION
```
Menjalankannya di mode mock = **benar-benar mengaktifkan blokir produksi**.
Ini celah mock yang serius. Tidak diuji, sengaja.

**e. `/retrainmodel` TIDAK di-guard.** `run_autotrain_from_file()` tanpa mock
guard; menarik sampel dari index ES `minisoar-labels-*` dan menulis model
produksi. Tidak diuji, sengaja.

**f. `/ai_provider <nama>` dan `/ai_model <nama>` menulis `.env` permanen.**
Hanya varian tanpa argumen (read-only) yang diuji.
